Completed work:
- Implemented the FIFO server startup and graceful shutdown skeleton.

- Implemented command dispatch behind the integrated protocol.
- Implemented per-file reader-writer locking.
- Added reader preference, writer preference, and fair policy constants.
- Added timed/abortable lock waits.
- Added reader-session ownership tracking for reader release correctness.
- Integrated wait-for graph hooks at wait, grant, and release points.
- Implemented a fixed 64-entry hash-backed LRU cache.
- Added valid/dirty bits and doubly linked LRU ordering.
- Added cache miss, eviction, dirty write-back, and flush behavior.
- Added cache hit/miss/eviction/writeback counters.
- Ensured disk I/O is not performed while holding the cache mutex.
- Added server shutdown order: drain workers, flush cache, save disk, destroy state.
- Added a configurable TCP listener.
- Added one connection thread per remote client.
- Sends fixed-size responses over each owning socket.
- Assigns connection-specific network session IDs.
- Keeps FIFO mode available for local testing.
